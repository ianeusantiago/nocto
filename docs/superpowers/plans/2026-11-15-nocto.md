# Nocto Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Uma "Dynamic Island" para Windows em Rust (Nocto): pílula translúcida com atalho global, barra de comando de comandos fixos, Spotify, calendário local e conversão de imagem por arrastar, com consumo mínimo de recursos.

**Architecture:** Um único binário Rust, interface nativa em Slint, sem navegador embutido. Lógica pura (tema, comandos, calendário, conversão de imagem) em módulos testáveis sem UI; integração com o Windows (atalho, mídia, vidro) em módulos finos separados. O processo fica dormindo e só acorda por atalho, clique, arrasto ou um único temporizador de virada de tema.

**Tech Stack:** Rust (estável), Slint, `windows` (windows-rs: `RegisterHotKey`, SMTC `Windows.Media.Control`, DWM backdrop), `image`, `serde`/`serde_json`, `ureq` com rustls para o Spotify. Versões: usar a mais recente estável de cada crate no momento da implementação.

**Spec:** `docs/superpowers/specs/2026-11-15-nocto-design.md`

## Global Constraints

- Rust nativo, interface em Slint; nada de WebView/Electron/Tauri.
- Prioridade máxima: não pesar nem atrapalhar jogo. Metas a medir: RAM parada 10–30 MB, CPU parada ~0%, nenhum quadro desenhado com a ilha oculta ou parada.
- Atalho global só com `RegisterHotKey`; proibido hook de teclado global e injeção em outros processos.
- Sem loop de verificação (polling); troca de tema por um único temporizador agendado para a próxima virada.
- Temas: Dia 05:00–15:59, Pôr do sol 16:00–17:59, Noite 18:00–04:59 (ajustáveis). Noite na família do INA (`#0b2a44` fundo, `#2bb4ff` destaque).
- Windows 11 é o alvo; no Windows 10, translucidez simplificada.
- Tudo gratuito, sem conta obrigatória, dados locais em arquivo.
- Comandos só pela lista de permissões (allowlist); ações sensíveis pedem confirmação.
- Fonte: Segoe UI Variable (nativa) com escala 12/14/17/21 px, pesos 400/600; não empacotar SF Pro sem confirmar a licença.
- Espaçamento base 4 px; raio de pílula 980 px; raio de cartões e campos 8 px.
- Nunca commitar sem o usuário pedir; por isso este plano não tem passos de commit.
- Antes da Task 1 (primeiro código), avisar o usuário para trocar o modelo para o Fable 5.2.

## Review Focus

Entradas e condições que o spec implica mas nenhuma funcionalidade principal testaria, da mais provável à menos:

1. Comando vazio ou só espaços na barra: deve ser ignorado sem erro nem ação (Task 3).
2. Arquivo do calendário ausente ou corrompido: o app abre com calendário vazio e não apaga o arquivo ruim (Task 4).
3. Arquivo arrastado que não é imagem, ou PNG com transparência indo para JPEG: erro claro no primeiro caso; fundo branco no segundo, sem crash (Task 5).
4. Atalho global já ocupado por outro app: Nocto avisa e continua rodando, sem sair (Task 6).
5. Spotify fechado ou sem dispositivo ativo ao pedir "toca X": mensagem clara, sem travar a barra (Task 8).

## File Structure

- `Cargo.toml`, `build.rs` — dependências, perfil release enxuto, compilação do Slint.
- `src/main.rs` — monta tudo; instância única; laço de eventos.
- `src/theme.rs` — `Period`, `period_for`, `next_switch_in`, paleta por período.
- `src/commands.rs` — `Command` e `parse` (puro).
- `src/launcher.rs` — executa `Command` pela allowlist.
- `src/calendar.rs` — `Calendar`, `Entry`, leitura/gravação em JSON.
- `src/imgconv.rs` — `convert_image`.
- `src/hotkey.rs` — registra o atalho global.
- `src/backdrop.rs` — vidro Acrylic/Mica via DWM, com alternativa simples.
- `src/media.rs` — controles de mídia do Windows (SMTC).
- `src/spotify.rs` — OAuth PKCE e `play_query`.
- `ui/island.slint` — pílula, barra de comando, calendário, zona de arrastar.
- `scripts/measure.ps1` — mede RAM e CPU do processo.
- `docs/PERF.md` — registro das medições.
